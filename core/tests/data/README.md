# Test Data

This directory contains test molecular structure files used by `yui-core` integration tests.

## Files

- `1hls.pdb`: PDB-format file containing a single NMR model (MODEL 1, 782 atoms) of human insulin-His(B16).
- `1HLS.cif`: PDBx/mmCIF-format file containing the full 20-model NMR ensemble (models 1–20, 782 atoms per model, 15,640 atoms total).
- `sample.mol2`: Tripos Mol2 format file containing ethanol (9 atoms, 8 explicit bonds).
- `multiframe.xyz`: a hand-made multi-frame XYZ trajectory for the `yui_core::xyz_trajectory` tests: 3 atoms (C, O, N) and 5 frames (`step=0, 10, 20, 30, 40`). From frame to frame every atom moves 0.5 Å in +x (frame `i`: C at `(0.5 i, 0, 0)`, O at `(1.5 + 0.5 i, 0, 0)`, N at `(0.5 i, 1.2, 0)`). Written by hand; no external source or license.
- `1hls_traj.xyz`: a 20-frame XYZ trajectory (782 atoms, `step=0, 10, ..., 190`) for trying trajectory playback by hand with `1hls.pdb` (same atom order). Generated by `mktraj.py` (`python3 -I mktraj.py 1hls.pdb 1hls_traj.xyz 20`): every atom is shifted in x and y by `0.5 sin(2π i/20 + 0.05 k)` Å (frame `i`, atom `k`). Derived from `1hls.pdb` (CC0).
- `mktraj.py`: the generator script for `1hls_traj.xyz` (any PDB and frame count). Not used by the automated tests.
